# Spectral Atlas

A visual language of optical instruments and quiet discovery. Deep ink establishes the field; violet and cyan act as precise signals rather than a blanket effect. The original NAI mark remains intact.

Each card has a miniature diagram that communicates its category through geometry: orbit, lens, code, diamond, manuscript, frame or signal. Index marks and fine grids give the series a coherent, meticulously crafted rhythm. These are original illustrations, not company logos.

The card has a calm reading surface and a separate optical layer. Body text and action placement stay consistent; category art adds identity without replacing labels. The composition is designed for scanning many tools at once.

Movement is physical but bounded: a soft pointer-driven spring moves the inner surface, not the layout shell. The outer shell remains reserved for the existing FLIP transitions. Touch devices and reduced-motion users receive stable, usable cards.

This adapts the visual-philosophy principle from Open Design canvas-design to live UI, together with frontend-design and emilkowalski-motion. It is not an invocation of the Open Design runtime or a static PNG/PDF workflow. Source: https://github.com/nexu-io/open-design/tree/main/skills

## Prism extension
Audience: students scanning a practical AI directory. Expressive moment: one physical orbital sculpture in the hero, with real HTML search kept readable. Card surfaces use restrained iridescent edge light only while engaged, not permanent animated borders. Search suggestions reuse catalog data, and the native dialog enters from the selected card geometry. Three.js is progressively loaded; local SVG is the no-network/no-GPU/reduced-motion fallback. The liquid-metal CSS is an original approximation, not the React metal-fx package. References: [Frontend Atlas](https://github.com/flash-hero/GOATED-UI-SKILL/tree/main/skills/frontend-atlas), [Meng To 3D object](https://github.com/MengTo/skills/tree/main/agent-skills/web-design/webgl-3d-object), [Impeccable](https://github.com/pbakaus/impeccable). No framework migration or build step.
