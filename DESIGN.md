# Spectral Atlas

A visual language of optical instruments and quiet discovery. Deep ink establishes the field; violet and cyan act as precise signals rather than a blanket effect. The original NAI mark remains intact.

Each card has a miniature diagram that communicates its category through geometry: orbit, lens, code, diamond, manuscript, frame or signal. Index marks and fine grids give the series a coherent, meticulously crafted rhythm. These are original illustrations, not company logos.

The card has a calm reading surface and a separate optical layer. Body text and action placement stay consistent; category art adds identity without replacing labels. The composition is designed for scanning many tools at once.

Movement is physical but bounded: a soft pointer-driven spring moves the inner surface, not the layout shell. The outer shell remains reserved for the existing FLIP transitions. Touch devices and reduced-motion users receive stable, usable cards.

This adapts the visual-philosophy principle from Open Design canvas-design to live UI, together with frontend-design and emilkowalski-motion. It is not an invocation of the Open Design runtime or a static PNG/PDF workflow. Source: https://github.com/nexu-io/open-design/tree/main/skills

## Prism extension
Audience: students scanning a practical AI directory. Expressive moment: one physical orbital sculpture in the hero, with real HTML search kept readable. Card surfaces use restrained iridescent edge light only while engaged, not permanent animated borders. Search suggestions reuse catalog data, and the native dialog enters from the selected card geometry. Three.js is progressively loaded; local SVG is the no-network/no-GPU/reduced-motion fallback. The liquid-metal CSS is an original approximation, not the React metal-fx package. ## V9 — Intelligence in Motion
The main experience no longer exposes the book/library or Ashen Press experiments; their files remain reachable by direct URL for provenance. The cinematic hero uses one original native WebGL filament field and a local SVG fallback based on the same parametric curves. No CDN, React, Three.js import, or build is required for the main page. The field cards select the actual directory category; the original bilingual catalog, search, favorites, comparison, finder, and details remain intact. Palette: graphite, lavender, restrained cyan and field-specific accents. Motion: mild scroll parallax, visibility-aware rendering, once-only section reveals and reduced card tilt. The coffee-site inspiration is conceptual, not a copy of an identified website.

## Atlas experience
Design intent: a compact editorial knowledge platform, not a collection of unrelated effects. The graph is a CSS/SVG navigation map with five real destinations and live catalog counts. The same navigation, command search, spacing and dark/light tokens apply across active pages. Motion is limited to lightweight line flow and interaction feedback and respects reduced motion. No new runtime dependencies. Old visual experiments remain archived but are not linked from active pages.

## Neural Atlas
The homepage uses six real navigation nodes around a central NAI orb, SVG radial paths, native Canvas 2D particle terrain and a synthetic rotating dotted sphere. The HTML links and CSS sphere remain available without Canvas. The preview changes on pointer hover and keyboard focus. All counts come from the existing catalogs and validated local favorite IDs. The globe is abstract rather than geographic. Motion is paused offscreen and when hidden and is disabled for reduced motion. Chose native Canvas/SVG/CSS over new Three.js/GSAP dependencies to preserve the static site and improve progressive fallback. No generated screenshot is used as the interface. Browser visual verification remains outstanding.
