# Research review

## Workflow

1. Clarify the research question and scope. Identify available sources and distinguish supplied evidence from external research.
2. Read relevant passages from actual sources. Track author, title, publication date, and link only when verified.
3. Compare methods, findings, limitations, and disagreements. Do not convert correlations into causal claims.
4. Build an evidence table and outline. Flag missing information instead of inventing citations or results.
5. Help the student explain the work and follow course integrity requirements.

## Example request

Compare supplied papers and prepare an evidence table for a literature review.

## Completion checklist

- Work from the actual project or supplied materials.
- Respect explicit user constraints and existing functionality.
- Keep credentials and personal data out of output.
- Report what changed and what has not been verified.
